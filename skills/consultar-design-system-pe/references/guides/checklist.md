# Checklist prático

Direto para uso em times de produto, design e gestão de serviços públicos, totalmente alinhado ao decreto.

## 1. Clareza do serviço

### Carta de Serviços

* [ ] O serviço está descrito de forma simples (sem juridiquês)?
* [ ] Está claro quem pode usar o serviço?
* [ ] Está claro o passo a passo?
* [ ] Todos os documentos exigidos estão listados?
* [ ] Os prazos estão informados?
* [ ] Existe explicação de como acompanhar a solicitação?
* [ ] A informação está atualizada no pe.gov.br?
* [ ] Existe consistência entre portal e outros canais?

## 2. Regras e exigências

* [ ] Não estamos pedindo nada além do que está na Carta de Serviços?
* [ ] Evitamos pedir documentos que o governo já possui?
* [ ] Eliminamos etapas desnecessárias?
* [ ] Não exigimos reconhecimento de firma sem necessidade?
* [ ] Não pedimos novamente algo já comprovado?

## 3. Experiência do usuário (UX)

* [ ] Linguagem simples, direta e sem siglas?
* [ ] Fluxo fácil de entender (sem pegadinhas)?
* [ ] Existe alternativa digital sempre que possível?
* [ ] O serviço funciona bem em celular?
* [ ] Há acessibilidade (visual, leitura, navegação)?
* [ ] O usuário sabe sempre onde está no processo?

## 4. Atendimento (presencial e digital)

* [ ] Atendimento respeitoso e igual para todos?
* [ ] Existe priorização legal (idosos, PCD, etc.)?
* [ ] O tempo de espera é monitorado?
* [ ] Existe opção de agendamento?
* [ ] Os horários e regras estão claros?

## 5. Ouvidoria (escuta ativa)

* [ ] Existe canal claro para reclamação/sugestão?
* [ ] O usuário consegue acessar facilmente?
* [ ] As respostas são em linguagem simples?
* [ ] Estamos respondendo dentro do prazo (20 + 10 dias)?
* [ ] Existe retorno claro sobre o que foi feito?

## 6. Dados e melhoria contínua

* [ ] Medimos satisfação do usuário?
* [ ] Monitoramos volume de reclamações?
* [ ] Identificamos principais dores do serviço?
* [ ] Publicamos resultados de avaliação?
* [ ] Usamos esses dados para melhorar o serviço?

## 7. Integração e digitalização

* [ ] O serviço está integrado ao pe.gov.br?
* [ ] Existe uso de tecnologia para simplificar o processo?
* [ ] Evitamos duplicidade de sistemas e cadastros?
* [ ] O agendamento (quando necessário) está centralizado?
* [ ] Informações são compartilhadas entre órgãos (quando possível)?

## 8. Governança e operação

* [ ] Existe responsável claro pelo serviço?
* [ ] A Carta de Serviços tem um dono (atualização contínua)?
* [ ] A ouvidoria está integrada com o time do serviço?
* [ ] Existem rituais de melhoria (mensais/trimestrais)?
* [ ] Há revisão periódica de burocracias desnecessárias?

## 9. Princípio final (checagem rápida)

* [ ] Um cidadão comum entenderia isso?
* [ ] Ele conseguiria resolver sem ajuda?
* [ ] Estamos facilitando ou complicando?
